Interactive SDK Support

Run pipelines directly with your existing terminal code

Atlas Flow allows visual builders to export directly to structured JavaScript JSON, or query instantly with HTTP POST endpoints. No convoluted configurations.

Step 1: Setup a triggering endpoint

Post payloads into the secure endpoint listed on your individual profile settings dashboard.

Step 2: Bind target servers visually

Map custom variables using simple markdown double-curly braces format easily.

atlas_payload.js 
// Fetch flow triggers
const atlas = require('@atlas-flow/sdk');

atlas.init({
    apiKey: 'at_live_839dfh9421',
    environment: 'production'
});

// Trigger the automated welcome cycle
atlas.trigger('Lead Created', {
    email: 'hello@company.com',
    name: 'Jane Smith',
    workspaceId: 'ws_9821a'
});
